# Open Design Lite v0.1.1

**日期**：2026-07-09
**类型**：补丁发布
**Tag**：`v0.1.1`

修复 GitHub Release 二进制（如 `odl-windows-x64.exe`）通过 MCP 调用 `artifact_preview` 时无法启动预览子进程的问题。

## 修复

- **`artifact_preview` 子进程路径**：改为使用 `std::env::current_exe()` 自引用 spawn，不再硬编码 `odl` 命令名。Release 资产任意命名（`odl-windows-x64.exe` 等）均可正确拉起 `preview` 子进程。

## 验证

- `cargo test --workspace`
- Release 二进制 `odl-windows-x64.exe mcp` + `artifact_preview` 返回 `started: true` 且预览窗口可打开
