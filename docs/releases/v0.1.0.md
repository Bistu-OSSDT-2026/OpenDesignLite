# Open Design Lite v0.1.0

**日期**：2026-07-09
**类型**：技术预览
**Tag**：`v0.1.0`

v0.1.0 是 Open Design Lite 的首个可发布技术预览。这个版本确认产品主路径：编码 Agent 通过 MCP 调用 `od-core` 创建、预览、交付和导出本地设计产物；`odl` CLI 保持为同一内核之上的脚本化辅助入口。

## 主要能力

- **MCP 工具面**：`odl mcp` 提供 JSON-RPC stdio server，并接入 `artifact_create`、`artifact_preview`、`artifact_handoff`、`artifact_export`。
- **本地产物闭环**：支持创建 HTML 页面、Markdown docs、轻量 HTML slides；每个 artifact 保持 plain files、`manifest.json`、主文件和 `handoff.md`。
- **实时预览**：`artifact_preview` 通过 MCP 托管的 `odl preview` 窗口打开本地预览，并默认监听文件变更刷新。
- **设计内核**：`od-core` 提供轻量 design tokens、CSS recipes、visual brief guardrails，不引入 React/Tailwind/shadcn 等默认运行时。
- **导出**：`odl export` 与 `artifact_export` 支持 `html`、`md`、`zip`、`pdf`；PDF 走本机 Chrome/Edge headless 打印路径。
- **内置技能**：`html-page`、`slides-html`、`docs-polish` 等 filesystem skill 以可读 `SKILL.md` 形式交付。

## 面向 Agent 的使用方式

Agent 应通过 MCP 工具驱动 Open Design Lite：

1. 启动 `odl mcp` 作为 MCP stdio server。
2. 调用 `artifact_create` 创建 artifact。
3. 调用 `artifact_preview` 打开持久、live-reloading 的预览窗口。
4. 调用 `artifact_handoff` 生成或刷新交付说明。
5. 调用 `artifact_export` 导出 `html` / `md` / `zip` / `pdf`。

预览时不要由 Agent 自行打开系统浏览器；应保留 `artifact_preview` 默认参数，让 MCP 托管的 `odl preview` 窗口处理预览和监听。

## 已知限制

- 各 Agent 的 MCP 配置说明和真实客户端联调仍需补齐。
- MCP transport 仍是手写 JSON-RPC stdio，尚未迁到 `rmcp`。
- Linux 预览依赖系统 WebKitGTK，缺失时需要用户安装依赖或使用 fallback。
- PDF 导出依赖本机 Chrome/Edge；找不到浏览器时返回 `pdf_backend_missing`。
- Markdown 预览暂不要求语法高亮。
- 自动更新、安装器和跨平台二进制分发流程尚未产品化。
