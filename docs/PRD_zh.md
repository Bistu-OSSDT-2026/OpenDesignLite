# PRD：Open Design Lite

## 摘要

Open Design Lite 是一款轻量级的本地设计助手，用于快速创建、润色、预览和交接小型设计产物：HTML 页面、Markdown 文档和轻量幻灯片。

本产品不是 Web 平台。它应像一款可从终端、编辑器或原生壳层快速打开的本地工具。

## 问题

重型 AI 设计工具启动慢、配置复杂，且对日常常见工作往往过度设计：

- 快速做一个 HTML 原型
- 润色一篇文档页面
- 起草一套幻灯片
- 预览并微调结果
- 交给编码 Agent 实现

用户更看重速度与低门槛，而非一体化设计平台。

## 目标

- 作为本地二进制程序快速启动。
- 在一分钟内创建可预览的产物。
- 产物以普通文件形式保存。
- 通过 CLI/MCP/交接文件与外部 Agent 协作。
- 提供原生预览壳层，无需浏览器标签页或 Web 开发服务器。
- 把前三种模式做到优秀：HTML、文档、幻灯片。

## 非目标

- 完整替代 Figma。
- 多用户协作。
- 插件市场。
- 云账号或同步。
- 重型项目管理。
- 通用编码 Agent 替代品。
- v1 完整可视化编辑器。

## 主要用户

- 使用 Codex、Claude Code、OpenCode、Cursor 或 Zed 的构建者。
- 需要快速文档、原型和演示的 PM/创始人。
- 希望在实现前获得可预览产物的工程师。
- 希望生成小型交付物、又不想打开大型设计套件的设计师。

## 产品形态

Open Design Lite 拥有一个核心运行时和多个入口：

- 原生壳层：主要 UI 与预览界面。
- CLI：可脚本化的本地工作流。
- MCP 服务：Agent 集成接口。
- 编辑器扩展：基于 CLI/MCP 的薄适配层。

## MVP 模式

### HTML 页面

输入：提示词、可选文件、可选风格说明。

输出：

- `index.html`
- 可选 `assets/`
- `handoff.md`

预览：原生壳层 WebView。

### 文档润色

输入：Markdown 或纯文本。

输出：

- `doc.md`
- 可选 `handoff.md`

预览：原生 Markdown 渲染。

### 幻灯片

输入：主题、大纲、粘贴的笔记或文档。

输出：

- `slides.html`
- 可选 `handoff.md`

预览：原生壳层 WebView。

## 核心工作流

1. 用户打开壳层或运行 `odl`。
2. 用户选择模式：HTML、文档或幻灯片。
3. 用户输入提示词或提供文件。
4. 内核创建基于纯文件的产物工作区。
5. 首个文件生成后立即打开预览。
6. 用户请求编辑。
7. 用户导出或交接给外部 Agent。

## 集成要求

一等公民的集成契约不是编辑器插件，而是：

- CLI 命令
- MCP 工具
- 纯文件
- 生成的交接提示词

插件应保持轻薄：

- 打开预览面板
- 将选中文本/文件发送给 `odl`
- 调用 MCP 工具
- 显示产物状态

## 成功指标

- 冷启动对小体量本地工具而言感觉近乎即时。
- 一条命令即可创建新产物工作区。
- HTML 预览无需项目配置。
- 文档润色无需浏览器。
- 幻灯片预览无需构建步骤。
- 仅凭文件即可理解如何交接给 Codex/OpenCode/Claude Code。

## 待决问题

- 在编辑器插件之前，应提供多少内联编辑能力？
- 最小可接受的导出集合是什么：仅 HTML/MD，还是包含 PDF？
