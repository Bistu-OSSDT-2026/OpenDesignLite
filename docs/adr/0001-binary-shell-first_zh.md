# ADR 0001：优先二进制壳层

## 状态

已采纳。

## 背景

产品应轻量、启动快，并适用于日常小型设计产物。曾考虑两种候选界面：

1. 独立二进制壳层，通过 CLI/MCP 预览产物并连接 Agent。
2. 编辑器专用插件，如 Codex/Cursor/Zed 侧边栏。

## 决策

优先构建独立二进制壳层。以 CLI 和 MCP 作为稳定的集成契约。编辑器插件后续作为薄适配层构建。

## 后果

正面：

- 单一核心运行时。
- 更快的 MVP 路径。
- 可从任意编辑器或终端使用。
- 避免插件 API 碎片化。
- 产物存储与预览行为保持一致。

负面：

- 后续仍需要薄插件以获得最佳编辑器体验。
- 壳层必须提供足够 UX，才值得单独打开。
- 需谨慎选择原生壳层技术栈，避免重蹈重型 Web 应用覆辙。

## 备注

使用系统 WebView 做预览是可接受的。被拒绝的是带开发服务器和复杂浏览器应用运行时的重型 Web 平台。
