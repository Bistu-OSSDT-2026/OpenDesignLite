# ADR 0001：二进制壳层优先

**状态**：已采纳  
**日期**：2026-06（仓库初始化）  
**替代**：插件优先、Web 平台优先

## 背景

产品需轻量、启动快，适用于日常小型设计产物。曾考虑：

1. 独立二进制壳层 + CLI/MCP
2. 编辑器专用插件（Codex/Cursor/Zed 侧边栏）

## 决策

**先构建独立二进制壳层。** CLI 与 MCP 为稳定集成契约；编辑器插件后续作为薄适配层。

## 后果

**正面**

- 单一核心运行时
- MVP 路径更短
- 任意终端/编辑器可用
- 避免插件 API 碎片化
- 产物存储与预览行为一致

**负面**

- 仍需薄插件以优化编辑器内体验
- 壳层 UX 需足够好，才值得单独打开
- 需谨慎选型，避免做成重型 Web 应用

## 备注

- 使用系统 WebView 预览 **可接受**
- 带 dev server 的重型 Web 平台 **拒绝**
- 调研曾建议 fork 大型 `open-design` 项目 → **未采纳**，见 [kernel-candidates.md](../research/kernel-candidates.md)
